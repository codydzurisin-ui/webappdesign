# Vacay — mobile app prototype

Clickable prototype of the Vacay vacation-rental app (Home → Search → Booking → Confirmed).

## Deploy on GitHub Pages
1. Upload everything in this folder to the root of a GitHub repo (keep the `.github` folder).
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. Push (or re-run the workflow). The site goes live at `https://<user>.github.io/<repo>/`.

No build step — `index.html` is self-contained.
